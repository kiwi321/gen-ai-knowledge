这些收藏，到底在教什么

你收藏它们，是因为里面可能有用。这页按「能学会什么」来写，不按帖子一条条复述。专有名词第一次出现会先解释。帖子里夸张的部分会说明白：哪些是可以练的方法，哪些只是演示视频。

怎么用这页

这五天刷屏的名字主要是 GPT-6 Astra（OpenAI 的新模型，特别擅长 3D 和自己操作电脑软件）、MiniMax H3（便宜的视频生成）、Seedance 2.5（画质更高的视频生成）、以及编码 Agent 里比较贵的 Fable。

它们看起来像四件无关的热闹，其实可以收成四件事来学：

  1. 让模型交出来的是还能继续改的文件，不是一张图。
  2. 做视频之前先问：你要的是「房间关系正确」，还是「看起来像随手拍」。
  3. 贵模型负责想和验收，具体干活交给更便宜的模型。
  4. 一句话做出来的网页是原型，不是上线产品。

下面每一节都是：这件事是什么 → 为什么值得学 → 你可以怎么做。文末的黑底文字是可以复制去改的模板，不是必须原样使用的咒语。

1. 3D 和游戏：交工程文件，不是交一张漂亮图

以前让模型「做个 3D」，你拿到的通常是一张渲染图，或者一段转圈视频。好看，但下一步没法改：不能换一把椅子、不能加碰撞、不能继续当游戏用。

这周 Astra 相关收藏的真正变化是：模型开始自己打开软件干活。常见软件包括 Blender（做 3D 模型的工具）、Unreal Engine（游戏引擎）、以及浏览器里的 three.js（用网页显示 3D）。它交出来的是工程：模型文件、场景、能在浏览器里玩的小游戏。

这件事值得学，因为后面你还能改。图改不了；工程可以继续往下做。

先决定你要哪种东西

想发一个别人点开就能玩的小东西：用网页 + three.js。这种技术不擅长写实，提示词里主动说「像动森 / 塞尔达 / 像素风」，等于把短板写成风格。

想要以后还能改的 3D 资产：用 Blender。让模型通过 MCP（一种让 Agent 调用外部工具的接口）或者直接操作软件界面（叫 computer use：把屏幕当按钮来点）去建模。你要的是 mesh（三维网格，真正的 3D 形状），不是一张图。

想做很大的世界：不要指望一条提示词。把世界切成一条街、一个房间，让 Agent 过夜一轮轮检查、修补。收藏里那些「连跑几天」的演示，说明的是工期按天算，不是「一句话出 3A 游戏」。

如果只是看一眼、不打算改：用视频模型更省事。但视频里没有场景结构，你改不了一扇门。

想好看，不要把提示词写得更长，要给它一张「标准答案图」

只写「赛博朋克、很美、很真实」，模型不知道停在哪算对。社区里比较有效的做法是：

  1. 先用图像生成，做出你想要的画面（概念图）。
  2. 让模型在 Blender 里搭场景。
  3. 截游戏里的画面，跟概念图对比，不像就继续改。
  4. 同时要求能跑到 60 帧，避免它用糊画面冒充画质。

这叫视觉闭环：有一张可以对比的图，优化才知道往哪走。有人 45 分钟出了很炫的画面，作者自己后来说那是画面演示，玩法还没做完。所以你学的是这套对比方法，不是「45 分钟做一个游戏」。

可以练：选一个很小的场景（一张桌子、一个房间）。先出 3 张概念图，再让 Astra / Codex 接到 Blender，循环改到截图接近概念图为止。完成的标志是：你能在 Blender 里选中物体并挪动它。
Blender 闭环，可改了再用
把 Codex 接到 Blender MCP。
1）先用图像生成，做出目标画风的概念图。
2）在 Blender 里建模。贴图也用图像生成，不要下载现成素材包。
3）截游戏内画面，跟概念图对比，一直改到接近为止，并跑在 60fps。
4）推理强度用 High。
完成标准：我能打开工程继续改，而不是只拿到一段预告片。
网页小 3D，可改了再用
新项目：网页 3D，three.js，用 Vite，要能在本地打开。
角色：____（外观、动作要能互相区分）
空间：____（多大、视觉中心在哪；哪些道具以后要单独加）
风格：不要写实。用圆角、像素或二次元（动森 / 塞尔达那种）。
相机能旋转、缩放。
完成标准：这是一份能继续加道具和动作的工程，不是一张图。

2. 做视频：先问你要骗过什么

视频模型和 3D 工具解决的不是同一个问题。视频模型擅长生成一段连续的画面。它并不真正记得「这栋房子有几间房、相机刚才从哪扇门出来」。所以下面两件事必须分开做。

你要空间连续：镜头穿过好几个房间，东西还在原处

如果直接对视频模型说「拍一条穿过七个房间的长镜头」，它很容易一边走一边编房间，后面的门对不上前面的墙。

比较靠谱的顺序是：先在 3D 里搭好这一集用到的空间，摆好人和相机，把整条路线走一遍；再从几个关键位置导出同一套视角的截图；最后才把这些截图和分镜交给 Seedance 这类视频模型去填成片子。3D 负责「房间关系别错」，视频模型只负责把画面变得好看。

以后要改镜头，就回到 3D 里改，再导出、再生成。不要在视频模型里让它「再想一次房间」。

可以练：只做两个相连的房间。先用 Astra 在 Blender 里搭好，导出 4 张同一相机体系的截图，再交给视频模型生成 6 秒。看它会不会把门走丢。

你要日常感：看起来像朋友随手拍的

这种片子要骗过的不是空间关系，而是「这是不是广告」。更贵的视频模型往往更像电影预告，不一定更像监控或手机。

H3 这类便宜模型够用，关键是把「不像广告」写成约束，而不是只写「超真实」：

  • 人的脸、发型、衣服从头到尾不要变。
  • 场景里不要品牌、地标、一堆路人。
  • 相机写成旧手机手持：晃、对焦来回找、曝光乱跳。禁止云台、无人机、慢动作。
  • 按每 5 秒写一件具体的事，不要写情绪形容词。
  • 声音只用环境声和笑声，不要配乐、旁白、字幕。

有人说 H3「不输」更贵的模型，那是在这种日常片上。要一镜穿过复杂空间，它不是自动胜任的。网上的「0.1 元/秒」是某个渠道的价，换地方会变，别当公式记。

另外：已经拍好的素材，可以用 Codex 加剪辑工具按你的口述去剪。那是在剪时间线，不是替你拍摄。

日常手持，可改了再用
做一段 30 秒、1080p、像朋友随手拍的视频。同一个人，做一件临时起意的小事。

人：脸、头发、衣服、包、饰品全程不变。
场景：普通街区，不要品牌、地标、广告、摆拍人群。
相机：旧手机手持。构图不稳、会晃、会对焦来回找、曝光会跳、有噪点和压缩。不要云台、无人机、慢动作、广告片质感。
时间：每 5 秒一件具体动作，写清楚在干什么。
声音：风、脚步、环境声、真的笑。不要配乐、旁白、字幕、水印。

最后的感觉：碰巧被朋友拍到，普通、不完美、是真的。

3. 带 Agent 干活：最贵的模型不要去搬砖

在 Cursor / Claude Code / Codex 这类编码 Agent 里，往往有一档更贵、更聪明的模型（这周收藏里常出现的是 Fable），额度大概只占总额度的一半。另外还有更便宜的模型真正去改文件、跑测试。

如果全程用最贵的那档去读几千行代码、做小修改，它会很快用完。后半周你就只剩较笨的模型，或者总额度先被便宜模型烧光，最强的那档反而浪费了。

可以记住一个分工：

  • 指挥：搞清楚要做什么、怎么拆、做完了对不对。强度用 High 或 Medium。不要动不动开 Max。Max 的意思是让它死磕更久，不是让它更会做架构，却按最高倍率烧指挥额度。
  • 工人：读代码、写代码、跑测试、批量改文件。交给更便宜的子 Agent。
  • 卫生：换一件事就清上下文；一件很长的事做到一半，压缩一下对话。看一眼两类额度是不是一起往下掉。对齐只说明你没乱烧钱，不说明你做对了。
可以练：下一件超过半小时的开发任务，主对话只写「拆任务和验收」，所有改文件都明确要求派给 subagent。做完看两类额度是不是大致一起下降。
贴在任务末尾
你主要负责分析、编排和验收。具体执行尽量交给 subagent。
你自己只做：把需求问清楚、拆方案、分任务、检查结果。
读大量代码、写代码、跑测试、批量修改，一律派给 subagent。不要选 Max 及以上。

做连续内容时，后面的步骤不许自己改剧情

短剧、系列视频、大场景都有同一个坑：每一步都想「再创意一下」，于是人物脸、房间、情节每张都不一样。

比较稳的顺序是：先定结构（有几集、每集发生什么）；再定人和世界长什么样；然后写剧本；最后才出分镜和视频。分镜这一步只负责「怎么拍」，不许回头改剧情。

「主角不要太多」「开场 3 秒里要有钩子」这类要求，如果只写在提示词里，模型经常假装遵守。写成检查脚本，不合格就失败——这才叫质量门。收藏里的 shuohao-skills 就是把这件事做成了可跑的流程，短剧只是一个例子。做游戏关卡或系列广告，也可以用同一骨架：结构 → 角色和世界 → 剧本 → 镜头。

还有一句很土、但比过夜建城更接近真实工作：很多人每天真正需要 Agent 做的，是整理信息（有人说是总结微信群）。接口和合规是另一回事；学习上只要分清——会演示的能力，和每天用得上的能力，不是同一张清单。

4. 做网页：先分清「能点开」和「能上线」

Codex 上有人在用 Product Design 这类插件：你说产品给谁用、在什么场景，它先定视觉方向和页面结构，再生成一个能打开的页面。这解决的是「从想法到第一版界面」。

它适合个人站、介绍页、演示用的后台壳。不适合当成已经做完的产品：登录权限、数据对不对、以后怎么改设计系统、快不快，都还没开始。

所以「前端要失业」这种话，学的时候直接丢掉。你要学的是：用它很快得到可以讨论的原型；真正做产品时，你（或工程师）还要把数据、权限、性能补上。

用 Gemini 也是同一类问题。平时打开的 Gemini 网页是聊天产品，模型和功能会被产品层裁过。你要试完整能力和「指哪打哪」改界面，去 Google AI Studio。别人说的「满血」，意思就是这个，不是有一个隐藏开关。

可以练：用一句话描述你自己的一个小工具（谁用、解决什么、打开后第一眼看到什么），在 Codex 或 AI Studio 里做出能打开的第一页。然后自己列一张清单：登录、数据存在哪、哪些状态会错。清单上的东西，就是原型还没覆盖的部分。

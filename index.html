1 · 空间

验收是场景图还在不在：mesh、材质、关卡、工程文件。视频可以骗过一次浏览，给不了第二次修改。

先选载体

要什么用什么边界
能转发的小可玩浏览器 + three.js风格服从引擎：圆角 / 像素 / voxel。不要写实。
还能改的资产Blender（MCP 或 computer use）价值在文件，不在渲染图。
开世界引擎 + 按区块过夜循环工期按天。一条 prompt 只够局部。
只看一次视频模型没有场景图，改一扇门就要整段重抽。

模型对比只在同一载体上有意义。单次对打、病毒视频，都不够当排行榜。

画质来自视觉闭环，不是更长的提示词

文本对美术方向是欠定的。先出目标概念图，再用游戏内截图去逼近，并钉死帧率。computer use 能进 Blender / Unreal / KiCad / Canva，证明的是「屏幕就是没做 API 的接口」，不是专业流程被替换。

闭环（一种做法）
Connect Codex to Blender MCP.
1) Image-gen concept frames of the target art style.
2) Model assets in Blender. Textures from image gen. No external packs.
3) Iterate until in-game screenshots match those frames, at 60fps.
4) High reasoning. Stop when the scene is editable, not when a trailer looks good.
网页 3D 骨架
新项目，网页 3D，three.js，Vite，可本地跑。
角色 / 空间 / 可扩展的道具写成独立模型。
风格主动规避写实短板（圆角、像素、二次元）。
相机可旋转缩放。验收：能继续加东西的工程，不是一张图。

2 · 视频

视频模型补像素，不持有空间。要房间关系，先建几何；要「像随手拍」，锁摄影机语言。两者不要共用工作流。

两条路径

空间连续日常手持
真正约束统一三维空间 + 同一套视角身份不变 + 手持缺陷 + 按秒事件
模型干什么只填像素，不发明建筑便宜模型通常够；更贵的买纹理，不买「更像监控」
改一处改场景图，再导出，再生成改某一秒，整段重抽

渠道价、积分换算都是个人账单，只说明数量级。H3 适合手持风，不自动胜任一镜多房间。短剧里，视频模型只出现在分镜层——前面的结构、人、世界没锁死，每张都会像不同的剧。

手持风：五锁
LOCK identity: face, hair, outfit, accessories — unchanged.
LOCK setting: ordinary streets, no brands, landmarks, ads, crowds.
LOCK camera: old handheld. Shake, autofocus hunting, exposure drift, noise. No gimbal, drone, slow-mo.
LOCK time: 5-second beats, one concrete action each.
LOCK audio: wind, footsteps, ambience. No music, narration, subtitles.
Feel: accidentally captured by a friend.

3 · Agent

智力花在澄清、拆解、验收。搬砖交给更便宜的工人。写给模型看的 checklist 等于没有——门必须能被脚本判失败。

指挥和工人分开

  • 指挥：判断和抽查。High / Medium。默认不上 Max——Max 买的是更长的死磕，却按最高倍率烧稀缺窗口。
  • 工人：读、写、测、批量改。
  • 卫生：换任务就清上下文；长任务中途压缩；哪条额度条超前就反向调。对齐是资源卫生，不提高智力。
指挥附言
你的任务是分析、编排和验证。具体执行交给 subagent。
只做需求澄清、方案拆解、任务分发、结果验收。
读大量代码、写代码、跑测试、批量修改，一律派给 subagent。不要选 Max 及以上。

多步生成必须收敛

后面的步骤爱做新决定，人物和房间就会每张都不一样。

  1. 先锁结构。大纲可以否定后面的一切；分镜不许回头改剧情。
  2. 人设、美术、剧本可来回校对，但不推翻骨架。
  3. 质量门是代码，能 validate 失败。
  4. 资产从上一层预填，禁止手抄出第二份真相。

短剧 skill 是这四条写得最清楚的一种实现（结构 → 角色/世界 → 剧本 → 镜头），不是唯一产品形态。shuohao-skills。能秀的过夜建城，和每天真有输入的生产，不是同一张清单。

4 · 界面

同一套权重，对话网页、Studio、编码 Agent 接到的不是同一层。界面生成停在可运行原型；再往前是工程。

先给方向，再填像素

顺序是：定位、用户、场景 → 视觉和信息架构 → 可运行页。适用 Landing、说明页、MVP 壳。不适用权限、数据一致性、设计系统、性能。把这一层说成「前端失业」，是把原型当成了工程。

Gemini 网页版是对话产品；要完整模型选择和构建控件，去 Google AI Studio。「满血」只是「没被产品层裁过」，不是开关。
